# 🚌 College Bus Live Tracking System

A real-time college bus tracking system designed to help students track their college buses and view their current location easily.

📌 About the Project

The **College Bus Live Tracking System** provides real-time bus location information using GPS/location services.
Students can check the current location of their bus and estimate its arrival, making daily college transportation more convenient and efficient.

✨ Features

* 🚌 Real-time bus location tracking
* 📍 Live GPS location updates
* 🗺️ Map-based bus location display
* 👨‍🎓 Student-friendly interface
* 🔄 Continuous location updates
* ⏱️ Helps students track bus movement
* 🔐 Simple and efficient system

🎯 Objectives

* To provide real-time college bus tracking.
* To reduce students' waiting time at bus stops.
* To improve the efficiency of college transportation.
* To provide a convenient and user-friendly tracking system.

⚙️ How It Works

1. The bus driver's/device location is obtained using GPS.
2. The location is updated in real time.
3. The latest bus location is stored and synchronized with the system.
4. Students can view the bus's current location on the map.
